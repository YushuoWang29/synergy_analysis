# 基于MyoKi数据集的手部姿态分析：任务级角度范围PCA（扩展至23名受试者）

- **纳入受试者 P01–P15 和 P17–P24**（共23人），因为他们使用相同的18传感器CyberGlove II配置且传感器位置一致。

- **P25–P35 被排除**，因为他们使用不同的传感器配置（不同的手套或传感器设置）。
- 所有纳入的受试者均为右利手，无已知手部运动功能障碍。

## 2. 任务选择

MyoKi实验方案包含多种日常生活操作任务。本分析聚焦于**抓取类任务**——即涉及主动抓握和操控物体的任务。非抓取动作（如指路、休息姿态、无特定目标的手部运动）被排除在外。

纳入分析的抓取类别包括：

| 抓取类别     | 描述                                              | 示例任务                              |
|------------|--------------------------------------------------|-------------------------------------|
| **圆柱抓取** | 围绕圆柱形物体的力性抓取                           | 举起不同重量的杯子和瓶子                |
| **球状抓取** | 围绕球形或圆形物体的力性抓取                       | 举起不同直径（65、85、100 mm）的球      |
| **钩状抓取** | 钩状抓握（基于张力，手指起钩子作用）                | 提起笔记本电脑包（0.75–3.0 kg），使用锯子 |
| **三指捏**   | 拇指、食指、中指参与的精巧抓取                     | 捏起茶杯边缘                          |
| **对指捏**   | 拇指–食指对立的精巧抓取                           | 用笔写字                              |
| **复合抓取** | 融合多种类别的综合抓取模式                         | 使用工具（锤子、螺丝刀）涉及力和精度成分   |

共筛选出 **41个不同的抓取任务**。每个任务由每位受试者执行多轮次（通常每人3–5次重复），总计 **5,656条试次记录**涵盖所有23名受试者。

详细任务列表见附录A。

## 4. 预处理流程

预处理流程旨在为每个抓取任务提取一个既紧凑又具代表性的特征向量。其核心思路是捕捉**每个关节在任务执行过程中的角度活动范围**，而非某个时刻的绝对姿态。

### 第1步：通道选择

每条原始记录包含18个CyberGlove通道。去除掌弓（通道15）、腕部屈伸（通道16）和腕部桡尺偏（通道17）通道，保留**15个手部相关关节角度**用于分析。

### 第2步：试次分割

每位受试者的记录包含带有任务标记的连续时间序列数据。根据任务标签识别试次边界，提取独立的连续片段作为单个试次。时长不足5帧（50毫秒）的试次作为不可靠数据剔除。

### 第3步：运动帧选择

为聚焦于主动运动而非静态保持，剔除低速度帧（梯度范数低于阈值0.5度/帧的帧）。这样可以排除静态姿态和过渡休息期，确保只将动态运动片段纳入活动范围的计算。

### 第4步：时间插值

为确保不同时长的试次之间的时间采样一致性，每个试次通过线性插值重采样至统一的100帧长度。这一步骤保留了完整的运动学轨迹，同时排除了时长这一干扰因素。

### 第5步：范围特征提取

对每个试次，计算15个关节各自的**角度活动范围**：

$$r_j^{(t)} = \max_{f \in \text{试次 } t} \theta_j(f) - \min_{f \in \text{试次 } t} \theta_j(f)$$

其中 $\theta_j(f)$ 是关节 $j$ 在第 $f$ 帧的角度值。

这一范围特征编码了关节在任务执行中的**活动幅度**——衡量该关节被调用程度的指标。与静态姿态指标（只捕捉一个时间点）或均值姿态指标（可能因正负运动相互抵消）不同，范围特征完整捕捉了每个关节的动态参与程度。

### 第6步：任务级聚合

同一任务的多次试次（跨所有受试者和重复）通过对每个关节取均值的方式进行聚合：

$$X_{ij} = \frac{1}{N_i} \sum_{t \in \text{任务 } i \text{ 的试次}} r_j^{(t)}$$

其中 $N_i$ 是任务 $i$ 的可用试次数。

由此得到一个 **41 × 15 的数据矩阵**，每行对应一个操作任务，每列对应一个关节。每个单元格表示该关节在该任务中的平均角度活动范围（度）。

未应用任何额外的归一化处理（如z-score或min-max缩放），从而保留了关节之间天然的大小差异。这使得本身活动范围较大的关节（如MCP关节）能够在分析中发挥与其生理特性相称的作用。

### 第7步：主成分分析降维

对该41 × 15矩阵执行主成分分析（PCA）。由于所有变量具有相同的物理单位（度），采用基于协方差的PCA自然地保留了数据的方差结构。保留前10个主成分用于分析。

平均姿态向量（所有41个任务向量的均值）与主成分载荷一同存储，用于后续重构。

## 5. 结果

### 方差解释

前两个主成分解释了数据集中**91.0%的总方差**：

| 主成分 | 方差解释率 | 累积解释率 |
|--------|:---------:|:----------:|
| PC1    | 78.04%    | 78.04%     |
| PC2    | 12.98%    | 91.02%     |
| PC3    | 3.29%     | 94.31%     |
| PC4    | 2.19%     | 96.50%     |
| PC5    | 1.40%     | 97.90%     |
| PC6    | 0.66%     | 98.55%     |
| PC7    | 0.61%     | 99.16%     |
| PC8    | 0.36%     | 99.53%     |
| PC9    | 0.18%     | 99.71%     |
| PC10   | 0.14%     | 99.85%     |

PC1和PC2的主导性贡献证实了手部抓取运动学可以用二维协同空间有效描述。与此前11名受试者的分析结果（PC1+PC2 = 90.9%）相比，前两个主成分的解释率基本不变（91.0%），充分证明了这一低维结构的稳健性。

### 关节载荷模式

**PC1**（78.04%方差）在所有15个关节上均呈现**正向载荷**，表明它描述的是一个所有关节协调一致的运动模式。载荷较高的关节包括中指（0.355）、无名指（0.365）和小指（0.338）的MCP关节，以及无名指（0.310）和小指（0.314）的PIP关节。该主成分捕捉了抓取的整体力度——更强的抓取驱动所有关节产生更大的活动范围。

**PC2**（12.98%方差）揭示了沿手部**桡侧–尺侧轴（中–外侧轴）的梯度模式**：
- **拇指**关节呈强正向载荷，尤其对掌（ThumbOpp: +0.729）和外展（ThumbAbd: +0.383）
- **食指**关节呈中等正向载荷（IdxMCP: +0.096, IdxPIP: +0.126）
- **中指**关节呈负向载荷（MidMCP: −0.132, MidPIP: −0.191）
- **无名指和小指**关节呈负向载荷，尤其PIP关节（RingPIP: −0.290, LitPIP: −0.239）

该主成分捕捉了拇指–食指驱动的精细操作与尺侧（无名指–小指）力量稳定之间的对比。依赖手部桡侧的任务（如精确捏取、三指捏取）与需要全手参与的任务（如大型物体的力性抓取）在该维度上自然分离。

### 与先前分析（11名受试者版本）的比较

两次分析的关键指标高度一致：

| 指标                 | 11名受试者 | 23名受试者 | 变化量  |
|---------------------|:---------:|:---------:|:-------:|
| PC1方差解释率        | 76.95%    | 78.04%    | +1.09%  |
| PC2方差解释率        | 13.97%    | 12.98%    | −0.99%  |
| PC1+PC2累积解释率    | 90.92%    | 91.02%    | +0.10%  |
| 试次数               | ~2,700    | 5,656     | ×2.1    |

在样本量翻倍以上的情况下，结果表现出显著的稳定性，这强有力地验证了人手抓取运动中存在一致的低维协同结构。

### 解释

这两个主成分模型捕捉了手部抓取的两个基本轴：

1. **PC1 — 整体抓取强度**：所有关节的协调调用，区分轻触式操作和力量型抓取。
2. **PC2 — 桡侧–尺侧梯度**：拇指–食指参与度与无名指–小指参与度之间的平衡，区分以精度为导向的任务和需要全手掌接触的力量型任务。

这两个维度共同构成一个功能空间，能够根据生物力学需求将41个抓取任务自然地组织起来。

## 6. 模型存储

PCA模型以NumPy `.npz` 格式文件存储，包含：
- `components`：(10 × 15) 主成分载荷矩阵
- `mean`：(15,) 关节角度范围均值向量
- `explained_variance`：(10,) 方差解释率
- `explained_variance_cumsum`：(10,) 累积方差解释率
- `n_tasks`：使用的任务数（41）
- `n_joints`：关节数（15）
- `data_label`：描述性字符串

该模型可被加载用于重构、可视化，或作为基于协同控制的基础模型。
